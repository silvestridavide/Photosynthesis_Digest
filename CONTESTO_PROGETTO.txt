PROGETTO
- Nome: Photosynthesis Digest · Vetrina Scientifica & Rassegna Letteratura.
- Scopo: Fornire una vetrina quotidiana, strutturata come una rivista scientifica online, per monitorare gli ultimi articoli e news pubblicati sulla fotosintesi in qualsiasi organismo (piante superiori, Chlamydomonas, Chlorella, cianobatteri, alghe rosse, diatomee o sistemi sintetici).
- Destinatario: Ricercatori del Laboratorio di Fotosintesi & Bioenergetica.

PERCORSO CANONICO
- Cartella canonica: LAVORO/TOOLS/Photosynthesis_Digest.
- Predecessore: Nessuno (nuovo tool scientifico autonomo).
- Repository GitHub: autonomo con branch main e sviluppo su branch agent/ dedicati.

INPUT E OUTPUT
- Input: 
  - File dati JSON (assets/data/articles.json) e modulo JS (assets/js/articles-data.js).
  - Ingestion via DOI singolo o multiplo tramite script Python (scripts/add_by_doi.py).
  - Ingestion automatica programmata via scheduled task giornaliero (scripts/daily_fetch.py).
  - Inserimento manuale istantaneo nel browser con persistenza locale (localStorage).
- Output:
  - Vetrina web responsive a schede dense con date ed autori in prima linea.
  - Modal di lettura con abstract completo, affiliazioni, ORCID e visualizzatore di citazioni accademiche (APA, BibTeX, RIS).
  - Esportazione istantanea del dataset in formato JSON, BibTeX (.bib) e CSV.

FLUSSO OPERATIVO
1. L'utente apre il tool da browser (locale o Vercel) per consultare le ultime pubblicazioni censite.
2. Filtra per macro-area (Cryo-EM, Rubisco, NPQ, Pirenoide, Bioenergia, ecc.) o per organismo modello, ordina per data o esegue ricerche libere.
3. Clicca su un articolo per leggere l'abstract completo, copiare il DOI o la citazione BibTeX/APA con un clic, o aprire direttamente la pagina dell'editore.
4. Salva gli articoli di interesse nei preferiti (memorizzati localmente nel browser).
5. Per aggiungere nuovi articoli, l'agente o lo scheduled task esegue `python3 scripts/add_by_doi.py <DOI>` oppure `python3 scripts/daily_fetch.py`: i dati vengono interrogati online, normalizzati e memorizzati senza modificare l'interfaccia.

DATI E REGOLE
- Nessuna allucinazione o sintesi interpretativa: solo dati fattuali verificati (titoli, autori, affiliazioni, riviste, date di pubblicazione, DOI e abstract integrali originali).
- Fonti ammesse: CrossRef, Europe PMC, PubMed Central e riviste peer-reviewed internazionali (Nature, Science, PNAS, Nature Plants, Nature Communications, The New Phytologist, Plant Cell & Environment, Bioresource Technology, ecc.).
- Ogni record possiede: id univoco, doi, title, authors (array con name, affiliation, orcid), journal, publication_date (YYYY-MM-DD), year, article_type, organism, category, tags, abstract, url, open_access, featured, added_at.
- Disaccoppiamento totale tra dati e vista: il catalogo viene renderizzato dinamicamente a partire dal file dati.

INTERFACCIA
- Masthead accademico con titolo editoriale, contatori in tempo reale (articoli tracciati, riviste censite, ultima pubblicazione) e pulsanti rapidi.
- Toolbar sticky con barra di ricerca full-text, selettori di filtro per area scientifica ed organismo, selettore di ordinamento (data desc/asc, alfabetico), pulsante segnalibri "Salvati" e reset.
- Sezione Spotlight per la scoperta di punta in evidenza.
- Griglia responsive a 1, 2 o 3 colonne con schede dense, badge colorati per rivista e data in evidenza, lista autori in grassetto, abstract clampato e pulsanti d'azione.
- Modal di lettura con abstract integrale, lista dettagliata degli autori, generatore di citazioni (APA, BibTeX, RIS) e pulsante di copia DOI.
- Drawer laterale per inserimento rapido via DOI e visualizzazione dei comandi CLI.
- Design responsive privo di overflow orizzontale su qualsiasi risoluzione (da smartphone 390px a desktop >1200px).
